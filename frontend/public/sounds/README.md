# Chat Sound Effects

Place your sound files in this directory with the following names:

## Required Files:

1. **typing.mp3** (or .wav, .ogg)
   - Sound played when participant starts typing
   - Recommended: Subtle keyboard typing sound
   - Duration: 1-2 seconds
   - Volume: Keep it low/gentle

2. **sent.mp3** (or .wav, .ogg)
   - Sound played when you send a message
   - Recommended: Soft pop, click, or confirmation sound
   - Duration: 0.5-1 second
   - Volume: Medium

3. **received.mp3** (or .wav, .ogg)
   - Sound played when you receive a new message
   - Recommended: Notification bell, chime, or alert sound
   - Duration: 0.5-1.5 seconds
   - Volume: Medium-High

## Recommended Sites to Download Free Sounds:

### 1. **Mixkit** (https://mixkit.co/free-sound-effects/)
   - Free, no attribution required
   - High quality
   - Search for: "keyboard typing", "notification", "pop", "click"

### 2. **Freesound** (https://freesound.org/)
   - Large library
   - Requires free account
   - Check license (most are CC0 or CC BY)
   - Search for: "typing", "message notification", "ui click"

### 3. **Zapsplat** (https://www.zapsplat.com/)
   - Free with account
   - High quality
   - Search for: "typing", "notification", "message"

### 4. **Pixabay** (https://pixabay.com/sound-effects/)
   - Free, no attribution required
   - Good selection
   - Search for: "typing", "notification", "message"

### 5. **OpenGameArt** (https://opengameart.org/)
   - Free game sounds
   - Search for: "ui", "notification", "click"

## Tips:

- **Format**: MP3 is recommended for best browser compatibility
- **File Size**: Keep files under 100KB each for fast loading
- **Duration**: Keep sounds short (0.5-2 seconds)
- **Volume**: Normalize audio levels (use Audacity or similar)
- **Quality**: 44.1kHz, 128kbps MP3 is sufficient

## Example Search Terms:

- **Typing**: "keyboard typing", "typing sound", "keyboard click"
- **Sent**: "pop", "click", "ui click", "button click", "soft click"
- **Received**: "notification", "message notification", "bell", "chime", "alert"

## After Downloading:

1. Rename files to match the required names above
2. Place them in this `sounds/` directory
3. The app will automatically use them!
